# UNO Pro Advanced — объединённый проект

## Состав

- Корень: актуальные runtime-исходники beta-сборки `v0.9.5-beta`.
- `Docs/`: документация, решения, тесты и release notes из актуальной beta-линии.
- `Reference/materials/`: исследовательские материалы из `D:\UNO\materials`, включая SysEx, карты состояния, декодеры и архивные справочники.
- `Reference/captures/`: свежие MIDI-monitor captures от 13.09.2026.

## Рабочие правила

См. `D:\UNO\AGENTS.md`. STORE/`0x28` остаётся заблокированным. Новую сборку создавать только по явной команде пользователя.

1. Исправить локальный пресет-селектор: до 20 файлов — простой список, свыше 20 — раскладка и навигация как у `UnoSynth`.

3. Не заявлять hardware PASS без проверки на физическом UNO.
