# UNO Pro Advanced — состояние проекта

Дата фиксации: 2026-09-13.

## Актуальная база

- Текущая beta-линия: `v0.9.5-beta`.
- Legacy-база: `v1.64 FIX2`.
- Последняя выданная сборка по рабочему чату: `v0.9.4-beta`; архив `v0.9.5-beta` содержит исправления Clock и верхней панели.
- STORE / `0x28` остаётся заблокированным.

## Подтверждено

- Выбор и чтение аппаратных пресетов, имена, current state и hardware sequence read через `0x29`.
- MIDI Clock и PLAY/STOP по USB-синхронизации.
- При `SYNC = Internal` редактор не генерирует `F8`, но сохраняет Start/Stop/Continue.

## Открыто

- Аппаратные секвенции некоторых пресетов не загружаются; официальные `.unosyp` показали переменную длину страниц и данные после 16-го шага.
- Требуется реальный двусторонний capture `0x29` для рабочего и проблемного пресета.
- SEQ ON/OFF остаётся без подтверждённой команды.

## Ближайшее UI-изменение

Локальный пресет-селектор должен использовать отображение hardware `UnoSynth`: до 20 файлов — простой список; более 20 — колонки и навигация по аналогии с hardware. Номер локального файла показывается отдельно и не используется как адрес UNO.
