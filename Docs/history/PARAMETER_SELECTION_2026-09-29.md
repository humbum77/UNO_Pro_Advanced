# Parameter Selection — что установлено проверкой (2026-09-29, версия 3)

Цель: закрыть блокер Parameter Selection.

Источники: данные, присланные оператором для `PSEL_A`…`PSEL_I`; база
`D:\Download\Temp\UNO_unosyp_full_step_database.csv`; файлы `D:\UNO\unosyp`;
`E:\UNO_Evidence\databases\UNO_UNIFIED_NORMALIZED_FINAL_2026-09-29.sqlite`.

## 1. Поле выбора найдено и подтверждено двумя источниками

Запись автоматизации для шага 1 в серии PSEL устроена так:

```
01  02  <sel>  20  20
│   │    │     └────┴── два значения, оба 0x20 = 32
│   │    └─────────── байт выбора параметра
│   └──────────────── число параметров в записи (2)
└──────────────────── номер шага (1)
```

Значения `20 20` совпадают с тем, что ставилось: два параметра по +32.

Значения байта выбора по данным оператора:

| съёмка | пара | sel |
|--------|------|-----|
| PSEL_A | ENV1 + SPACING | 0x20 |
| PSEL_B | ENV1 + DRIVE | 0x00 |
| PSEL_C | ENV1 + REVERB | 0x00 |
| PSEL_D | ENV2 + SPACING | 0x44 |
| PSEL_E | ENV2 + DRIVE | 0x50 |
| PSEL_F | ENV2 + REVERB | 0x00 |
| PSEL_G | SPACING + DRIVE | 0xA0 |
| PSEL_H | SPACING + REVERB | 0x64 |
| PSEL_I | DRIVE + REVERB | 0x00 |

Независимое подтверждение: колонка `automation_encoded_records` в полной базе
шагов для файлов `corpus_recheck_20260927/sources/PSEL/PSEL_*.unosyp` даёт
`202020`, `002020`, `002020`, `442020`, `502020`, `002020`, `a02020`, `642020`,
`002020` — первые байты совпадают с таблицей один в один.

## 2. Поле зависит от пары, а не от одного параметра

Ни один параметр не имеет постоянного байта:

| параметр | в скольких парах | значения sel |
|----------|------------------|--------------|
| ENV1 | 3 | 0x00, 0x20 |
| ENV2 | 3 | 0x00, 0x44, 0x50 |
| SPACING | 4 | 0x20, 0x44, 0x64, 0xA0 |
| DRIVE | 4 | 0x00, 0x50, 0xA0 |
| REVERB | 4 | 0x00, 0x64 |

Следовательно байт кодирует комбинацию, а не отдельный параметр.

## 3. REVERB не участвует

Самый сильный сигнал в данных: **все четыре пары, содержащие REVERB, дают
0x00** (PSEL_B, PSEL_C, PSEL_F, PSEL_I). Все пять пар без REVERB ненулевые
(PSEL_A, D, E, G, H).

Из десяти возможных пар пяти параметров REVERB входит в четыре, и все четыре
дали ноль. Совпадение не выглядит случайным и требует объяснения: либо REVERB
не входит в этот список параметров, либо для него запись не пишется.

## 4. Композиционной модели нет

Проверены перебором все 256 значений на параметр, для моделей
`p(x) op p(y)` и `g(x) op h(y)` при op = OR, XOR, сумма по модулю 256.
Ни одна не даёт решения, совпадающего со всеми девятью парами.

Модель суммы подбирается под пять ненулевых пар:
ENV1=86, ENV2=122, SPACING=202, DRIVE=214, REVERB=154. Но это пять уравнений
на пять неизвестных, поэтому решение гарантировано и ничего не доказывает.
На четырёх независимых нулевых парах модель ошибается все четыре раза
(предсказывает 0x2C, 0xF0, 0x14, 0x70 вместо 0x00). Считать законом нельзя.

## 5. Отозванное утверждение версии 2

Версия 2 утверждала, что поле выбора — это 16-битная маска по смещению
0x01ED, и приводила дифф девяти файлов из `D:\UNO\unosyp\PSEL_*.unosyp`
(15 различающихся байт, маски 0x0040…0x0700).

**Это утверждение снято.** Причина: в файлах `D:\UNO\unosyp\PSEL_*.unosyp`
паттерн `XX 20 20` из раздела 1 не встречается ни разу, а каталога
`corpus_recheck_20260927` на диске нет. То есть `D:\UNO\unosyp\PSEL_*.unosyp`
— не те файлы, которые несут байт выбора. Дифф был проведён на другом наборе,
и вывод о маске относился не к тому объекту.

Что из версии 2 сохраняется: запись автоматизации сама по себе параметр не
называет, и имя файла достоверным основанием не является — оба вывода
получены на других файлах и новыми данными не опровергнуты.

## 6. Что нужно для закрытия

Пять съёмок, по одной на параметр, значение +32, остальные сняты:

```
PSEL_S1 — только ENV1 = +32
PSEL_S2 — только ENV2 = +32
PSEL_S3 — только SPACING = +32
PSEL_S4 — только DRIVE = 32
PSEL_S5 — только REVERB = 32
```

Это даст байт каждого параметра в одиночку. Дальше видно, складываются ли
байты пар из байтов одиночных, и отвечает ли REVERB нулем в одиночку — то есть
подтверждает ли раздел 3.

Если одиночные байты сложаются в байты пар, механизм закрывается. Если нет,
поле окажется кодом пары, и тогда понадобится таблица на все пары, что дороже
и на 23 параметра не обобщается.

## 7. Что делать нельзя

- Считать модель суммы законом: она подогнана под пять точек и опровергнута
  четырьмя.
- Использовать файлы `D:\UNO\unosyp\PSEL_*.unosyp` как носители поля выбора:
  в них его нет.
- Считать имя файла меткой параметра: 21 группа побайтово идентичных файлов с
  конфликтующими именами, например `ENV1_32` = `SPAC_32` = `TEST_ENV1_PLUS32`.
