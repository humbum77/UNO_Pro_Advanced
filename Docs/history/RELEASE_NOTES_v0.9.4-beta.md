# v0.9.4-beta

Исправлено сохранение длинных секвенций. Модель теперь всегда содержит 64 шага, а при загрузке `.unosyp` сохраняет исходные переменные страницы и расширения. Данные после 16-го шага больше не заменяются пустой последовательностью длиной 16.

Проверено на официальных BASS_ (активный шаг 31) и PUNCH BASS 3_ (активный шаг 64), а также регрессионными тестами предыдущей версии. Аппаратная проверка по MIDI в этой среде не выполнялась.
