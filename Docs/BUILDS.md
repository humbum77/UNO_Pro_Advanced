## Расхождения, зафиксированные при сборке

1. **Имя архива ≠ содержимое.** Сборка №6 лежит в файле `beta3-`, а её `VERSION`
   равен `beta2-`; сборка №8 лежит в файле `HARDWARE-AUTOMATION-FIX`, а её канал
   `MPC-PADS-edit`. Имя файла нельзя использовать как идентификатор сборки.
2. **`VERSION` застыл с 2026-09-25** при минимум восьми сборках. Различает их
   только `BUILD_CHANNEL`, который не упоминается в `README.md` и `PROJECT_STATE.md`.
3. **Числа прогонов тестов расходятся** между `Docs/history/`, `PROJECT_STATE.md`
   и фактическим прогоном. Актуальное число приведено в `Docs/history/BASELINE.md`.
4. **`Docs/` синхронизирован разом 2026-09-25 18:39**, хотя внутри файлов даты
   с 09-22 по 09-25 — метка времени не отражает дату содержания.

## Источник истины по матрице модуляции

`UNO_MATRIX_FULL_REGISTRY.csv` в корне проекта. Это единственный файл из восьми
версий реестра в `Table.zip`, удовлетворяющий контракту кодека: 38 источников,
54 назначения (49 видимых), полные и уникальные FILE id.

Пять назначений скрыты в селекторе прошивкой, но остаются читаемыми:
`Pitch` (0x01), `LFO 1 Retrigger` (0x16), `LFO 2 Retrigger` (0x19),
`Gate Out 1` (0x22), `Gate Out 2` (0x24).

Геометрия: 32-битная ячейка маршрута на `MATRIX_BIT + slot*32`, 6-битный
идентификатор источника разрывает границу — младшие 3 бита в `base-3`,
старшие 3 бита в `base+0`. Подтверждено `UNO_MATRIX_CAPTURE_VALIDATION.csv`.
