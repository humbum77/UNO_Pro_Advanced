# UNO Pro Advanced v0.9.7-beta

Дата сборки: 2026-09-17.

## Что изменено

- Локальные файлы `.unosyp` и данные, полученные от устройства через SysEx `0x29`, декодируются общей реализацией.
- Полностью поддержано чтение Gate, Accent и TIE.
- Для аппаратного чтения секвенсора собираются страницы 0–4.
- Обновлена анимация огибающей.
- Отрезок S–R на графике огибающей увеличен на 30%.

## Защита утверждённой огибающей

Новая огибающая и весь код её анимации имеют статус **LOCKED / НЕ ИЗМЕНЯТЬ**. Любые прямые и косвенные изменения запрещены без отдельного явного указания пользователя.

## Проверка

Декодер проверен на контрольных файлах `REF C2`, `REF C2 G1`, `REF C2 G7`, `REF C2 G10`, `REF C2 A1`, `REF C2 A 27`, `REF C2 A127`, `TIE1ON`, `TIE2ON` и `DUA BASS A2`. Для локального файла и эквивалентного аппаратного payload получены одинаковые Gate, Accent и TIE.

Статус проверки: SOFTWARE PASS на предоставленных captures. Физический обмен с синтезатором этой проверкой не заявляется.

Перед отправкой в GitHub также пройдены compileall, `git diff --check`, проверка версии, защищённой геометрии огибающей и parity декодера на 10 captures. Исторический набор unittest: 55/57 PASS; два теста содержат прежние ожидания, несовместимые с утверждённым новым декодером и текущей темой, поэтому код под них не откатывался.

## Не изменено

STORE и SysEx `0x28` остаются заблокированными до полного подтверждения безопасного формата записи.
