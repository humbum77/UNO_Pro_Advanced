# UNO Pro Advanced — аудит и кандидаты на очистку

Дата аудита: 2026-09-12.

## Граница проверки

Проверены доступные прошлые ветки проекта, инвентарь `/UNO`, папки `/UNO/ZIP`, `/UNO/UNOSYP`, `/UNO/SysEx`, официальные руководства и сборки v1.54, v1.60, v1.61, v1.62, v1.63 и v1.64. Старые чаты могут индексироваться неполно; поэтому техническая актуальность дополнительно проверялась по содержимому сборок.

## Актуальная база

- Текущая накопительная сборка: `UNO_Pro_Advanced_v1.64.zip`.
- v1.64 построена на v1.63 и содержит согласованные изменения от 2026-09-12.
- Восстановлена внутренняя база GUI `1600×1000`; исправлено вертикальное обрезание v1.63.
- Масштаб выбирается из верхнего меню `⛶`; пункт UI Scale удалён из Settings.
- STORE/`0x28` остаётся заблокированным.
- `0x36` остаётся экспериментальным current-buffer preview.
- Read-only `0x29` интегрирован; чтение пресетов кроме 001 требует аппаратной проверки.
