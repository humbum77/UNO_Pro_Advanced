UNO Test Lab SAFE v1.2
НОВОЕ:
PLAY FA / STOP FC — транспорт без запуска Clock.
CONTINUE FB и MMC PLAY/STOP — экспериментальные, не поддержаны по MIDI Chart UNO.
Start F8 / Stop F8 — независимая генерация Clock, BPM 20–300.
STOP FC не выключает Clock. STOP MIDI выключает весь обмен и генератор.
Точность таймера Windows/Tk диагностическая, не аппаратная.
READ STATE 37 — ручной запрос F0 00 21 1A 02 03 37 00 00 F7.
Mark BEFORE / SEQ ON / SEQ OFF / AFTER и Add note — только заметки, без отправки.
Для поиска SEQ ON/OFF: отметка, READ STATE, физическое переключение UNO,
следующая отметка и READ STATE. Сохранить журнал для сравнения.
Порты сохраняются после успешного подключения; Refresh сохраняет доступный выбор.
Show MIDI Clock включает и исходящие тестовые F8; по умолчанию они скрыты.
Шесть программных тестов; визуальная и аппаратная проверки не выполнялись.

Базовая работа:
Основа: UNO Synth Pro MIDI Monitor v1.0 STANDALONE SAFE.
Отдельная утилита для Windows с Python 3 и Tkinter. EXE/Python runtime в архив не включены.
Запуск: распаковать весь ZIP, открыть bin\start.bat.

Сохраняется исходная схема прокси из четырёх портов:
Physical UNO INPUT = UNO Synth Pro
Physical UNO OUTPUT = UNO Synth Pro
EDITOR OUT / TAP INPUT = UNO_TAP
EDITOR IN / RETURN OUTPUT = UNO_RETURN
UNO_TAP и UNO_RETURN — разные виртуальные порты loopMIDI.
Для ручного CC-теста запуск редактора не требуется, но четыре порта
нужны исходному режиму SAFE Proxy. Нажать Start Proxy.

Выбрать Send channel, CC и Value. Send value отправляет указанное значение.
Send 0 / Send 64 / Send 127 отправляют ровно одно соответствующее значение.
Изменение выбора CC, канала или значения ничего не отправляет.
Автоматического перебора нет. После каждой команды наблюдать реакцию UNO.
TEST→UNO в журнале означает завершение вызова выхода MIDI, а не подтверждение
реакции синтезатора. Save сохраняет журнал с выбранными портами и HEX.

Доступны только 33 согласованных CC:
2,3,4,6,8,10,11,27,33,34,42,43,52,83,84,85,86,87,88,89,94,99,106,
115,116,117,118,119,121,124,125,126,127.
CC82 исключён. Согласно предоставленному MIDI Chart эти 33 CC имеют No/No;
исследование не означает, что за ними подтверждены функции UNO.

Clock F8 и Active Sense FE скрыты из захвата по умолчанию, но проходят
через прокси. Фильтры не скрывают ручные исходящие тесты.
STOP MIDI / Ctrl+Shift+F12 останавливает пересылку и удаляет ожидающие команды.
Это отключение MIDI, а не откат параметров, изменённых ранее на устройстве.
Не выполняются автоматические запросы состояния, каталога или STORE.
Не добавлены неподтверждённые команды SEQ ON/OFF.

Проверки выполнены без подключённого синтезатора; результат на UNO проверяется вручную.
